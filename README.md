# Trash4Impact

Trash4Impact is a gamified community volunteering app designed to motivate people to make a positive environmental and social impact. Users can discover nearby volunteer opportunities through an interactive map, track their cleanup contributions, earn points, climb leaderboards, and redeem rewards such as gift cards. By incorporating game mechanics like ranks, streaks, and leaderboards, we aim to make volunteering more engaging and encourage consistent community participation. Our goal is to empower individuals to take action and work together toward cleaner, greener communities.

This application was created for the Congressional App Challenge and not all features may be working or polished. If we created a 2.0 version, our main goal would be to move from a locally stored demonstration to a reliable, scalable platform. We would add a backend database, user authentication, live volunteer opportunities, and an organization dashboard so nonprofits could create and manage events directly. We would also improve location services by allowing users to share their location voluntarily, enter a location manually, and filter opportunities by distance, date, accessibility, and availability.

## Set up

1. Install an extension like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) to run a local development server.
2. Open your browser to localhost:5500 to see your code changes in real time.
3. Note that index.html is the landing page and app.html is the main app.

The demo requires an internet connection as the demo needs to load Leaflet and fonts from external CDNs.
